# Feed Service

**Feed Service** — это сервис, отвечающий за формирование ленты публикаций. За хранение самих публикаций отвечают сервисы, в которых они создаются (например, `user-service`, `materials-service` и т.д.).

## Какие бывают публикации

В зависимости от сервиса у публикаций могут быть разные типы соответственно и структуры:

- **Посты пользователей** — приходят из `user-service`
- **Посты сообществ** — приходят из `society-service`
- **Статьи** — приходят из `materials-service`
- Возможны и другие типы, если их создают дополнительные сервисы

## Структура базы данных

База данных Feed Service содержит две основные таблицы:

- `entities` — хранит содержимое событий от Kafka:
    - `external_uuid` — `uuid` публикации в исходном сервисе
    - `metadata` — название сервиса, где была создана публикация

- `entities_suggestion` — хранит информацию, кому рекомендуется определенная публикация:
    - `post_uuid` — ссылка на публикацию из `entities`
    - `target_uuid` — `uuid` пользователя, которому рекомендуется эта публикация

## Как работает формирование ленты

1. Приходит запрос в сервис на создание ленты с `uuid` пользователя.
2. По таблице `entities_suggestion` находятся N публикаций, рекомендованные этому пользователю.
3. Для каждой публикации запрашиваются полные данные из соответствующего сервиса (например, `user-service`, `society-service`) по `external_uuid`.
4. Готовая подборка собирается в массив из полной информации публикаций и отправляется на `frontend`.

## Как работает система рекомендаций

- Публикации пользователя на данный момент **рекомендуется только его подписчикам**.
- Сортировка публикаций происходит по времени создания.

## Как добавить поддержку новых видов публикаций

Чтобы `Feed Service` мог принимать и обрабатывать публикации из нового сервиса, нужно:

1. **Создать consumer** для Kafka-топика нового сервиса
2. **Добавить клиентскую ручку** на ваш сервис (ручка возвращает полную информацию оп массиву `uuid`)
3. **Добавить блок if** вызов вашей клиентской ручки в методе `GetFeed`

## Используемые технологии:

- PostgreSQL
- Kafka
