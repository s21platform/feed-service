# Feed Service. Сервис публикаций

## Описание

**Feed Service** — это сервис, формирующий ленту публикаций (посты или статьи) на основе событий из других сервисов. Он не создаёт публикации напрямую, а получает информацию об их создании через Kafka, обрабатывает её и сохраняет данные в собственную базу данных.

### Основная логика сервиса:

1. Сервисы (например, `user-service`, `society-service`) создают публикации.
2. После создания публикации соответствующий сервис отправляет сообщение в Kafka с `uuid` публикации.
3. `Feed Service` получает сообщение с помощью consumer'ов для каждого сервиса, затем handler'ы обрабатывают полученные данные и записывают `uuid` публикации в базу данных.
4. В базе данных 2 таблицы: 
   - `entities` - хранит `external_uidd` (`uuid` публикации из сервиса) и информацию, из какого сервиса публикация;
   - `entities_suggestion` - хранит `post_uuid` (`uuid` из таблицы `entities`) и `target_uuid` (`uuid` пользователя, которому будет рекомендоваться публикация).
5. Из таблицы `entities_suggestion` берется последние N публикаций и формируется лента рекомендаций.

## Используемые технологии и их применение:

- PostgreSQL – хранение uuid постов, информации из какого сервиса пост, время создания и uuid пользователей, которым будут рекомендоваться посты.
  [Работает через библиотеку github.com/jmoiron/sqlx]

- Kafka – реализованы consumer'ы, которые принимают события о новых постах. [Работает через библиотеку github.com/segmentio/kafka-go]
