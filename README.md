# Feed Service. Сервис постов

## Описание

Сервис постов является прокси-сервисом, который формирует ленту постов. За хранение постов отвечают сервисы, в которых эти посты создаются.

## Сервис работает со следующими технологиями:

- PostgreSQL
- Kafka

## Применение используемых технологий:

- PostgreSQL – хранение uuid постов, информации из какого сервиса пост, время создания и uuid пользователей, которым будут рекомендоваться посты.
  [Работает через библиотеку github.com/jmoiron/sqlx]

- Kafka – реализован consumer, который принимает сообщения из USER-SERVICE о создании поста.[Работает через библиотеку github.com/segmentio/kafka-go]
