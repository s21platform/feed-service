# Feed Service. Сервис постов

## Описание

Сервис постов является прокси-сервисом, который формирует ленту постов. За хранение постов отвечают сервисы, в которых эти посты создаются. После создания поста, в feed service с помощью kafka приходит сообщение с uuid поста. Он записывается в таблицу entities в столбец externel_uuid. Затем в таблицу entities_suggestion в столбец post_uuid записывается uuid из entities.

## Сервис работает со следующими технологиями:

- PostgreSQL
- Kafka

## Применение используемых технологий:

- PostgreSQL – хранение uuid постов, информации из какого сервиса пост, время создания и uuid пользователей, которым будут рекомендоваться посты.
  [Работает через библиотеку github.com/jmoiron/sqlx]

- Kafka – реализованы consumer'ы, которые принимают сообщения из сервисов о создании постов.[Работает через библиотеку github.com/segmentio/kafka-go]
